This log records milestones and outstanding engineering work, not a file-by-file changelog. **Verified** items were checked in the repository or Git history. **Handoff** items are historical claims from `FinPilot_Handoff.md` that were not reproduced here. **Open** means status is unknown or needs a decision.

Later commits added the Redis/arq worker foundation and Redis configuration. - **Committed — Layer 2 categorization:** Commit `2e7f70e` adds category kinds and transaction categorization state, the constrained Anthropic tool contract, an arq worker with atomic writes/retries, review/accept routes, stale-row sweeping, JSON log formatting with request IDs propagated to categorization and invoice jobs, and a manual labeled-CSV evaluation harness.

No persistence migration was needed.
- **Committed — weekly digests:** Commit `252f510` adds Monday scheduling for the prior full UTC week, company-scoped cash-flow/category/budget aggregates, constrained summary wording with deterministic fallback, a saved-digest read API, and private owner/accountant email delivery through a retryable outbox. Migration `b7e934ac1256` was manually reviewed and applied by the test setup to `finpilot_test` only. The full suite passed 143 tests. SMTP delivery was mocked, not live-tested; without SMTP host/from configuration digests are saved but not emailed.
- **Committed — frontend contract gaps (`416ef63`):** Adds caller role and currency to company-list responses, bounded/filterable transaction listing, scoped invoice-file download, and purchase/sale plus idempotent invoice confirmation without converting invoices into cash transactions. Migration `c4fa9d9f20a1` was manually reviewed and applied to `finpilot_test` only. Focused tests: 17 passed; full suite: 153 passed. - **Frontend milestone — auth and company shell (working tree, ready for human checkpoint):** Added the strict Vite/React/TypeScript app scaffold, generated OpenAPI types and typed `openapi-fetch` client, auth/session handling, sign-in and registration, company directory/create/switch flow, role-aware shell, dashboard placeholder, settings, and owner-only legacy-currency assignment banner.
